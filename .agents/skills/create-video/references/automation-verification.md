# create-video 自动化验证记录

## 实际完成的管线运行

使用现有暗物质六段模板，由新命令初始化工程、本地生成完整旁白、绘制 13 张关键帧和海报，检查后编码完整 60 秒/1080p/30 FPS/1800 帧 MP4，再做全片媒体验收。该测试不发布到生产网站，也不是 10 秒 Demo。

- audio 阶段：64.04 秒。
- keyframes 阶段：1.62 秒。
- render 阶段（含进程调度/初始化）：83.74 秒。
- verify 阶段：8.49 秒。
- 渲染器帧绘制/编码实测：83.23 秒，21.63 FPS。

将 video.json 的网页描述改动后，再执行 run --through docs，实际耗时 0.262 秒。audio/keyframes/render/verify/docs 五步全部 CACHE，音视频文件 SHA-256 和修改时间完全不变。这个数字是缓存重跑，不代表新主题创作或网站发布的总耗时。
