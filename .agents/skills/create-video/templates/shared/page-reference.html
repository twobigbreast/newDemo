08–23 秒 / 旋转曲线

外围恒星，为何仍转得很快？

扩展普通物质模型的速度在外围下降，而许多真实星系呈现较平坦的趋势。加入扩展暗物质晕，模型可解释额外引力。本片曲线是教学模型，不是某座星系的实测数据。

23–37 秒 / 子弹星系团

主要质量峰，与热气体分离

碰撞中气体减速，多数恒星则穿行。引力透镜重建的主要质量峰与气体峰存在偏移。光学星系、X 射线气体与透镜重建量是三种不同的信息。

37–49 秒 / 结构增长

为宇宙网提供引力基础

在标准模型中，暗物质帮助早期密度扰动增长。普通物质的冷却、气体动力学及恒星形成同样重要；宇宙网不是暗物质发光云的照片。

公式有适用条件

v(r) = √[G M(r) / r]

这里的 M(r) 是半径内的总质量。该关系用于球对称分布的圆轨道近似。本片用扩展 Plummer 普通物质分布与伪等温暗物质晕解释差异，没有把盘状星系全部可见质量直接视为中心点质量。精确盘模型需要计算盘的引力势。

图中的白线是典型平坦旋转趋势的示意，橙线和青线来自明确的质量模型。它们没有真实测量误差条，也不代表对某个观测样本的拟合。

证据很强，身份仍待揭晓

约 5% 普通物质、27% 暗物质、68% 暗能量，是标准宇宙学模型下今天总质能密度的近似比例。暗物质和暗能量不是同一成分。

目前尚无被普遍接受的暗物质粒子直接探测结果。轴子、WIMP 等是候选解释；修正引力也是研究方向。多种独立观测共同支持标准暗物质模型，不意味着微观本质和所有理论问题都已解决。
